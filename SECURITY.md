# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately via GitHub:
**Security** tab → **Report a vulnerability** ([direct link](https://github.com/sebastianmaute/x4-rebirthed-explorer-suite/security/advisories/new)).

Include what you found and how to reproduce it. This is a hobby project, so please allow a few days for a response.

Problems in third-party software this project builds on (the game, its mod tools or frameworks) belong to the
respective projects.
